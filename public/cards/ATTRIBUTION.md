# Card face images

The 52 PNGs in this folder are rasterized (240px wide, resized from the
source SVGs) from:

https://github.com/hayeah/playing-cards-assets (`svg-cards/`), MIT License,
Copyright (c) 2018 Howard Yeh.

That repository's own artwork traces back to the public-domain
[vector-playing-cards](https://code.google.com/p/vector-playing-cards/)
project.

Rasterizing kept the deck lightweight (the source SVGs run 400KB-1.1MB each
for the face cards) without changing how the cards look — same standard
English-pattern deck, just delivered as small PNGs instead of heavy vector
paths.
